## GitHub contributor display

The credits above describe work on this project. GitHub generates its Contributors display from Git history and account-linked email addresses; editing this file or `package.json` does not create an entry there. See [GitHub's contributor documentation](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-a-projects-contributors).

Codex assistance can also be recorded in the relevant commit message with `Assisted-by: OpenAI Codex`. This records AI assistance without assigning it an unverified GitHub account or email address. GitHub controls which accounts appear in its sidebar.
